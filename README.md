# آکادمی نخبگان — پلتفرم جامع مدیریت مؤسسه آموزشی

سامانه کامل و حرفه‌ای مدیریت آموزش: از ثبت‌نام دانشجو و مدرس تا برگزاری کلاس لایو، ذخیره جلسات، مالی و حسابداری، مدیریت شعب و داشبوردهای مدیریتی.

## ✨ امکانات

### 🎓 آموزش
- مدیریت دوره‌ها، کلاس‌ها و گروه‌ها با ظرفیت و زمان‌بندی خودکار جلسات
- جلسات کلاس با وضعیت (برنامه‌ریزی‌شده / لایو / برگزارشده / لغو)
- حضور و غیاب دقیق در هر جلسه (حاضر / غایب / تأخیر / موجه)
- تکالیف با ارسال و تصحیح و نمره‌دهی و بازخورد
- آزمون‌های چهارگزینه‌ای با تصحیح خودکار
- ضبط جلسات (Recordings) برای مرور دانشجویان
- گواهینامه خودکار با کد استعلام عمومی

### 🔴 کلاس لایو (Real-time)
- اتاق کلاس زنده با socket.io
- چت هم‌زمان با ذخیره تاریخچه در دیتابیس
- لیست حاضران لحظه‌ای، دست‌بلندکردن
- وایت‌برد مشترک هم‌گام‌شده بین همه کاربران
- کنترل شروع/پایان پخش زنده توسط مدرس + اعلان خودکار به دانشجویان
- دوربین و میکروفون (getUserMedia) با fallback گرید

### 💰 مالی و حسابداری
- ثبت پرداخت‌های شهریه (نقدی / کارتخوان / آنلاین / کارت‌به‌کارت)
- طرح اقساط خودکار + پیگیری اقساط معوق
- مدیریت هزینه‌های مؤسسه با دسته‌بندی
- فیش حقوقی اساتید با محاسبه خودکار از ساعات تدریس × نرخ ساعتی
- گزارش مالی کامل: درآمد/هزینه ۱۲ ماه، سهم دوره‌ها، روش‌های پرداخت
- لیست بدهکاران و مطالبات

### 🏢 ساختار و دسترسی
- چند شعبه‌ای با مدیر مستقل هر شعبه
- سالن‌ها/کلاس‌های فیزیکی
- ۵ سطح نقش: مدیر سیستم، مدیر شعبه، کارمند پذیرش، مدرس، دانشجو
- اطلاعیه‌های هدفمند + اعلان‌های لحظه‌ای + تیکت پشتیبانی
- گزارش کامل فعالیت‌ها (Audit Log)

## 🚀 اجرا

```bash
# نصب وابستگی‌ها
bun install

# ایجاد دیتابیس
bun run db:push

# داده‌های نمایشی
bun scripts/seed.ts

# سرور اصلی
bun run dev

# سرویس کلاس لایو (پورت 3003)
cd mini-services/live-service && bun --hot index.ts
```

## 🛠 تکنولوژی

- **Next.js 16** (App Router) + TypeScript
- **Tailwind CSS 4** + shadcn/ui + رابط کامل فارسی RTL با فونت وزیرمتن
- **Prisma** + SQLite
- **socket.io** برای کلاس لایو
- احراز هویت JWT با کوکی httpOnly + هش scrypt (بدون وابستگی خارجی)
- **Recharts** برای نمودارها
